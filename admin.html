1-Klik Simpan & Publikasikan ke GitHub Pages

Dengan integrasi REST API ini, seluruh pembaruan foto, teks profil, riwayat kerja, dan dokumen yang Anda simpan di sini akan langsung di-commit ke repositori GitHub Anda. Portofolio live Anda akan otomatis ter-update tanpa perlu membuka kodingan lagi.

💡 Cara Membuat Token GitHub (Hanya 1 Menit & Gratis):
1. Buka akun GitHub Anda ➔ Klik foto profil di pojok kanan atas ➔ Settings.
2. Gulir ke paling bawah ➔ Klik Developer Settings ➔ Personal access tokens ➔ Tokens (classic).
3. Klik Generate new token (classic) ➔ Centang izin repo ➔ Klik Generate ➔ Salin kodenya ke kotak di atas.
